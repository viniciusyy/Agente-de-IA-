# Memória procedural: planejamento de produção

Versão: `procedimento_planejamento_v1`

1. Identifique a intenção: consulta, recomendação, explicação, memória ou registro.
2. Verifique se a feira, a data ou o identificador necessários foram informados.
3. Use consulta estruturada para registros e busca textual para regras do domínio.
4. Para uma recomendação, use a ferramenta determinística e copie exatamente os totais retornados.
5. Mostre as restrições, o método, as limitações e as fontes.
6. Antes de qualquer registro, apresente a ação completa; o nó humano realizará a pausa.
7. Termine declarando se a base foi suficiente e qual é a próxima ação possível.
