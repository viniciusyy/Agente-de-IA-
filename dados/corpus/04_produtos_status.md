# Produtos e categorias

Os produtos são agrupados nas seguintes categorias:

- Comuns;
- Especiais;
- Doces.

Os produtos comuns ocupam os códigos de `1` a `19`.

Os produtos especiais ocupam os códigos de `20` a `24`.

Os produtos doces ocupam os códigos de `25` a `27`.

O pastel de Banana simples está temporariamente descontinuado.

Ele não deve entrar na recomendação enquanto esse status permanecer, mas poderá voltar no futuro.

Essa situação é diferente de uma proibição permanente da feira.
